- [ ] 四种语言都能正确回答草莓蛋糕、演唱会、摩天轮、三个结局与结局一延续问题。

## 环境

- [ ] Windows 10或11 x64。
- [ ] Steam已合法安装《不存在的莉莉丝》。
- [ ] 游戏目录此前没有BepInEx和本Mod。
- [ ] 系统没有单独安装Node，且没有设置 `LILITH_NODE_PATH`。

## 安装与启动

- [ ] ZIP的SHA-256与上方一致。
- [ ] 解压后 `winhttp.dll` 与 `Lilith.exe` 同级。
- [ ] 从Steam直接启动成功，首次缓存生成结束。
- [ ] 断开网络或屏蔽 `unity.bepinex.dev` 时，首次启动仍可使用包内 `BepInEx/unity-libs/2021.3.45.zip` 完成缓存生成。
- [ ] `LogOutput.log` 中没有 Unity基础库下载失败、`no plugins will be loaded` 或 `UnityEngine.CoreModule` 缺失错误。
- [ ] 没有常驻BepInEx控制台窗口。
- [ ] 任务管理器中的Companion使用包内 `BepInEx/plugins/companion/node.exe`。

## 核心功能

- [ ] 右键角色可以打开“和莉莉丝聊天”和“一起听歌吧”。
- [ ] 右键菜单不会在 `LogOutput.log` 中出现 `PlayerLineController.ShowOptions` 的 `MissingMethodException`。
- [ ] 中文输入、Enter发送和Shift+Enter换行正常。
- [ ] AI回复同时进入历史并显示在角色上方。
- [ ] 展开历史后滚轮平滑，关闭再打开保留本次游戏内窗口位置。
- [ ] 点击可交互的原生台词会打开对话并追加为莉莉丝首句。
- [ ] 莉莉丝位于主屏、无任务栏右侧副屏及上下/错位副屏时，右键角色和托盘入口打开的聊天框都在当前可见屏幕内。
- [ ] 当前会话和长期记忆在重启后恢复。
- [ ] 修改游戏内玩家称呼后，原生称呼与AI称呼同步，旧记忆自动迁移。

## API与联网

- [ ] Mod设置窗口能打开且没有外部PowerShell控制台常驻。
- [ ] 自定义及至少一个官方/方舟预设可以保存和测试连接。
- [ ] API密钥只出现在 `%APPDATA%\LilithAI\config.json`。
- [ ] 未开启搜索时不会声称已取得实时资料。
- [ ] 开启可用搜索后，天气、电影或歌曲问题能够取得实时上下文。
- [ ] Gemini 官方预设默认显示 `gemini-3.6-flash`、`gemini_interactions` 与 `low`，切换 Provider 后各自 API Key/模型仍能恢复。
- [ ] Gemini 普通问题未调用 Google Search 时不打开独立窗口，也不产生来源按钮。
- [ ] Gemini 实际搜索时，游戏聊天显示回复与可点击来源，独立窗口同时显示 grounded 原始输出、引用与 Search Suggestions，且每轮只启动/更新一次。
- [ ] 关闭结果窗口后下一次实际搜索可以重新打开；同一轮页面刷新或重复访问显示已失效。
- [ ] `%APPDATA%\LilithAI\sessions` 不含 thought、signature、`google_search_call` 或 Search Suggestions；重启后仍能基于可见历史继续对话。
- [ ] 缺少 WebView2 Evergreen Runtime 的干净环境会使用默认浏览器打开完整结果页。
- [ ] 显式 HTTP/HTTPS 代理、`HTTPS_PROXY/HTTP_PROXY` 与直连均可用，代理不影响 Companion loopback 通信；含认证或 SOCKS 地址会被拒绝。
- [ ] 游戏启动后后台只查询一次 GitHub 最新正式 Release；当前已是最新版时不弹提示。
- [ ] 假服务返回较新版本时，四语确认框只出现一次；选择“否”不打开浏览器，选择“是”打开对应 HTTPS GitHub Release。
- [ ] GitHub 断网、超时、404 或 429 时不弹错误窗口，不影响聊天、音乐和游戏启动，日志不包含响应正文。
