# 《不存在的莉莉丝》Mod v0.3.1

v0.3.1 是面向 v0.3.0 的兼容性修复版本，重点改善当前音乐问答、混合语言回复和模型输出格式容错。

## 下载

- `The-NOexistenceN-of-Lilith-Mod-v0.3.1-win-x64.zip`
- `The-NOexistenceN-of-Lilith-Mod-v0.3.1-win-x64.zip.sha256.txt`

## 修复

- 识别“我在听什么歌”“我听的是哪首”“现在放的什么”等自然表达，并继续支持当前曲目评价与类似音乐推荐。
- 单独谈到歌曲、音乐史或游戏配乐时不再无条件注入本机当前曲目。
- 中文回复可以引用日文歌名、英文品牌和其他语言专有名词，不会仅因少量混写触发语言重试。
- 模型偶尔以纯文本输出的 `emotion=`、`animation=` 内部字段不再显示在聊天正文或写入可见会话历史。
- 合法情绪值继续交给游戏原生对话系统；模型动画字段保持协议兼容，但不会接管角色动作。

## 升级

完全退出游戏后，将新 ZIP 的全部内容覆盖到游戏目录。`%APPDATA%\LilithAI` 中的 API 配置、聊天历史和玩家长期记忆不会被安装包覆盖。

本版本不修改 Gemini、Google Search、代理、WebView2 或播放器配置方式，v0.3.0 的现有配置可直接继续使用。
