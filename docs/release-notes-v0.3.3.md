# 《不存在的莉莉丝》Mod v0.3.3

v0.3.3 适配游戏更新后的菜单和多显示器地面逻辑。候选版先供当前更新版本验收，通过后再发布为正式 Release。

## 候选包

- `The-NOexistenceN-of-Lilith-Mod-v0.3.3-candidate-win-x64.zip`
- `The-NOexistenceN-of-Lilith-Mod-v0.3.3-candidate-win-x64.zip.sha256.txt`

## 修复

- 右键角色重新可打开“和莉莉丝聊天”和“一起听歌吧”。Mod 会在运行时选择游戏提供的新版三参数菜单接口，并兼容旧版两参数接口。
- 跨屏拖动实验性优化适配原生分段地面碰撞体。拖动时会临时移除冲突的地面，松手后按鼠标所在显示器恢复地面。
- 上下排列或有重叠区域的显示器在松手后会短暂锁定目标屏，避免原生刷新把角色拉回上屏。
- 关闭 Mod 的实验性跨屏优化时，会恢复游戏自己的完整地面布局。

## 已知限制

- 游戏新增的“默认音乐播放器”由原生 `ExternalPlayerLauncher` 处理。干净安装也可能无法启动 QQ 音乐等应用；这不是 Mod 菜单补丁造成的，本版本不修改该原生设置。
- 跨屏优化仍需在游戏“设置 → 控制”中开启“跨屏拖动”。关闭 Mod 优化后，垂直跨屏行为由游戏原生实现决定。

## 安装

完全退出游戏后，将候选包全部内容覆盖到游戏目录。`%APPDATA%\LilithAI` 中的 API 配置、会话历史、玩家记忆和游戏 Steam 云存档不会被候选包替换。
