# v0.3.4：自动网络恢复与模型预设更新

修复部分网络环境中官方模型接口 TLS 建连停滞，导致聊天显示“声音没有传过来”的问题。重启后的成功不能说明此前没有失败，本版会记录失败和恢复过程，便于诊断。

- 系统 DNS 优先；直连官方接口 TLS 建连失败时，自动通过阿里 DNS `223.5.5.5` 重试一次。成功后该域名优先使用备用解析 10 分钟，重新加载配置时清除缓存。
- 建连限制为 5 秒；网络重试与语言纠正共享原有请求超时，不重复写入对话。参数、认证、余额错误不会切换 DNS，TLS 证书验证保持开启。
- 设置新增默认开启的“连接失败时自动尝试备用 DNS”，支持简中、繁中、英文、日文。手动 DNS 配置继续有效，代理连接遵循现有代理流程。
- “测试连接”使用捆绑 Node 和聊天共用请求模块，密钥仅通过标准输入传递。诊断日志记录失败阶段、DNS 方式、耗时和重试状态，不记录密钥或正文。
- 新建 DeepSeek 默认 `deepseek-flash`，可选 `deepseek-v4-pro`；火山方舟默认 `deepseek-v4-1-flash-260910`，提供有效 Flash/Pro 型号。Kimi、Qwen、GLM、Gemini 默认保持原样，已保存或手填型号保留。
- 原生玩家称呼设置保留旧版刷新兼容，并支持游戏新版已移除旧设置控制器的情况。

型号参考：[DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/pricing-details-cny/)、[火山方舟官方列表](https://docs.volcengine.com/docs/ark/model-list?lang=en)。

## 安装与升级

完全退出游戏，下载 `The-NOexistenceN-of-Lilith-Mod-v0.3.4-win-x64.zip`，核对同页 SHA-256，解压全部文件到游戏根目录并覆盖旧文件，使 `winhttp.dll` 与 `Lilith.exe` 同级。

升级保留 API 设置、预设、聊天历史、长期记忆和游戏存档。Mod 用户数据位于 `%APPDATA%\LilithAI`，安装包不包含这些内容；不要删除该目录，额外备份时可复制整个目录。

旧版会在下次游戏启动时检查最新正式版，也可从 Mod 设置手动检查。发现新版后仍需玩家确认才会打开下载页，更新功能不会自动替换文件。
